# 星帆 TV / StarSail TV

面向 Fire TV / Android TV 的原生影视浏览客户端，基于 [AresCNZJ/DpadTV](https://github.com/AresCNZJ/DpadTV) 修改的**非官方版本**。使用独立名称、帆船图标和包名 `com.harrymeit.starsailtv`，保留 GPL-3.0 许可证及作者归属。

## V1 预览版

- 固定导航：首页、电影、电视剧、综艺、动漫、搜索、历史、设置。直播与片源管理仍可直接进入。
- 首页：精选、继续观看、最近更新、榜单热门、豆瓣高分与本机收藏。
- 搜索：遥控器字母数字键盘、拼音首字母/全拼/中文/英文别名联想、搜索历史。选择建议后使用真实片名调用 LibreTV 多源搜索。
- 分类：地区、类型、年份筛选；资源更新、榜单热度和豆瓣评分排序；对整个缓存快照排序后分页。
- 保留 Media3 播放器、选集、换源、续播、播放缓存、直播与原有片源导入通道。

## 数据范围与准确性

这是客户端缓存优先版本，没有新增收费服务、数据库或全量目录后台。

目录从已启用的非成人 Apple CMS JSON 接口分页读取，并结合 LibreTV `/api/hot-list` 榜单，最多缓存 6000 个条目。首页和分类页标明缓存范围，不能理解为全站完整排行榜。点击“加载更多目录”扩展快照，再对整个快照筛选排序。

`updatedAt` 来自资源 `vod_time`，不拿上映年份代替；缺失更新时间、热度或评分的条目放在对应排序末尾。豆瓣分只使用明确标注来源的榜单评分，不采信资源站的通用 `vod_score`。同名不同年份分别保存；未知年份的榜单条目仅在共享豆瓣 ID 时与片源目录合并。

拼音联想只覆盖已缓存、已搜索过的影片及收藏。尚未收录的作品不会凭空生成中文片名，应使用中文/英文查询或先扩展目录。英文匹配取决于目录提供的别名。推荐和元数据目录不保证有可播片源，查询不到时显示空状态。

历史、收藏、目录和搜索记录保存在本机；切换服务器或启用源集合时使用独立目录缓存。没有跨设备同步，也不收集点击/播放遥测。

## 构建

已验证工具链：JDK 25、Gradle 9.5.0、AGP 9.3.0、Android SDK 37.0。最低 Android 6.0（API 23）。

1. 配置 `JAVA_HOME` 和 Android SDK，复制 `local.properties.example` 为 `local.properties` 并填写 SDK 路径。
2. 可选填写公开的 `dpadtv.defaultUrl`；密码在应用设置中输入，不要把真实密码编译进分享的 APK。
3. 在 PowerShell 中运行：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug --console=plain
```

输出：`app/build/outputs/apk/debug/app-debug.apk`。这是调试签名的预览版，可与原版 DpadTV 共存；尚未完成 Fire TV 真机验收。

运行真实服务契约测试时，在测试进程环境中设置 `STARSAIL_TEST_PASSWORD`；未设置时该项测试跳过。测试不会将密码写入源码或 APK。

## 安装与使用

将 APK 安装到已允许应用安装的电视。在“设置 → 服务器设置”填写 LibreTV HTTPS 地址和访问密码，连接后导入服务器默认源。

遥控器上下左右移动、OK 确认、返回逐级返回。搜索页可用字母键盘，中文输入选择“中文 / 系统输入”。播放器保留原来的快捷键与设置。

## 验证与限制

自动测试包含拼音匹配、年份隔离、评分来源、空字段排序、缓存分页、收藏持久化、遥控器键盘与焦点恢复；另有真实 LibreTV 登录、搜索、详情、目录、评分榜单和 HLS 契约测试。Robolectric 原生布局预览不等于 Fire TV 真机测试。

实机仍需验证方向键、返回层级、滚动与焦点、H.265 硬解、长时间播放、切集、换源与弱网重试。V1 不提供全量目录、AI 个性化推荐、多用户、手机触控版或离线下载。
